# Segurança

Não abra uma issue pública para relatar uma vulnerabilidade ou possível exposição
de dados. Use **Security → Report a vulnerability** neste repositório para criar um
GitHub Private Vulnerability Report.

Os logs de um scan central são públicos. Um relatório deve informar apenas o `run_id`
do GitHub e o horário aproximado; não inclua token de publicação, chave de assinatura,
upload ID, checksum, URL interna, conteúdo do pack ou findings com trechos de código.
